Six alternatives for the complete-collection cards: A illustrated rail, B facing panels, C debate poster, D split programme, E illustrated window, F compact exchange. Every design puts the existing description directly beneath the title and gives the speaker pairing a visible VS.

The comparison defaults to the first two exchanges. Controls show any one debate or all nine in each layout, and switch between light and dark themes.
