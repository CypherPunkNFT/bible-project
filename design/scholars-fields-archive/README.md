Open `/mockups/scholars-fields-archive/` on the original 8931 preview, or choose **Scholars - saved 04 Fields** in the mockup gallery. `assets/` freezes the layout, React code, fonts, profile data and 7,119-entry subject index as they stood. Source components and featured IDs are saved in `source/`. The snapshot is not rebuilt by normal site builds, so future live catalogue changes cannot replace this design.
