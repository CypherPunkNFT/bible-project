# Chapter Summary Studio preview

`index.html` is the static, illustrative preview generated by `scripts/chapter_summary_studio.py --preview`. Opening the file does not start a server or call the model. The live Python workbench is at `http://localhost:8947` when its server is running.

Read the [project documentation](../../initiatives/chapter-summaries/README.md) and [handoff](../../initiatives/chapter-summaries/HANDOFF.md) for the approved format, saved databases, trial outcomes, and operating instructions. The latest evidence-first drafts are in the separate comparison report, not embedded in this illustrative HTML.
