# Teachers artwork motion study

Two category columns: Preachers & authors, and Scholars. Three rows: A clear existing scene; B signal and discovery; C shelf-to-page relationships. Hover or focus each sample; Animate all variants compares their loops simultaneously. Both themes and reduced motion are supported.

The live Teachers station receives only the contrast improvement. New motion directions remain here for comparison.

Artwork derives from the repository’s own StationArt SVGs. Regenerate markup from Website root:

`node node_modules/esbuild/bin/esbuild design/teachers-art-motion/generate.tsx --bundle --platform=node --format=cjs --jsx=automatic --outfile=.local/teachers-art-generate.cjs`

`node .local/teachers-art-generate.cjs`
