## How to work here

Read the path overview and the study's working page before developing it. Record confirmed decisions separately from proposals. Develop one study, then one subcard, at a time; retain useful alternatives without presenting them as settled decisions.

For each subcard, develop the central question, anchor passage, context, explanation, supporting passages and possible reader interaction. A card is a unit of content at this stage, not a component specification.

Use passage references while exploring. Verify wording against the local Bible text before inserting quotations. Keep textual observations, interpretive conclusions and proposed applications distinguishable.

Site implementation is a separate task. These working documents do not require routes, UI code, generated data, a build or deployment.
