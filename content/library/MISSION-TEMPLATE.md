## Run handoff checklist

- Mission ID and exact author/source/edition boundary.
- Inventory citation, date and expected counts (null if unknown).
- Last completed item and next item; no hidden job left running.
- Canonical record IDs and raw-source path used.
- Rights and automated-access evidence, including conditions.
- Duplicate resolution and edition/translation choices.
- Text, attribution and Scripture quality findings.
- Remaining gaps, source failures and decisions.
- Validation command/results; editorial review type and scope.
- Publication/KnowledgeBase changes, if explicitly part of this mission.
