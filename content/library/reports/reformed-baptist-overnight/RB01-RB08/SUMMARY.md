These figures count witnesses, volumes, chapters, articles and editorial material—not 561 new books or eleven million approved unique teaching words. Distinct file paths and original hashes do not establish distinct underlying works.

[Verification](verification.json) checks all originals and derivatives plus exact prepared-slice parent/member/range replay. This is a prepared reconciliation queue, not a database import. ## Reconciliation priorities

1. **Identity and extent:** apply source-supported normalized corrections for Stan Reeves versus Dagg, Samson's Appendix contribution, Andrew versus Francis Fuller, Horatius versus Andrew Bonar, Baxter Part II, revised Carey editions and the Carson desk's non-Carson contributors. Keep original bytes immutable and record correction provenance; existing DB rows were not silently relabeled in these missions.
2. **Attribution and scope:** retain authors, editors, translators, correspondents, opponent quotations, Scripture quotations, notes and reviews as distinct roles. Incomplete or rejected exposition cannot become complete commentary merely because the file is readable. Conservative Presbyterian comparisons remain distinct from Baptist ordinances/polity.
3. **Rights:** public reading is not an unrestricted corpus or public-hosting license. Preserve each work's actual permissions. The 2012 Tyndale canon essay has explicit noncommercial indexing/software permission; that permission does not automatically apply to unrelated modern articles or authorize commercial/derivative distribution.
4. **Deduplication:** the 191 prepared slices are reused source units, not 191 new downloads. Same-parent line-range reconciliation found no intersecting selected range pairs; different editions, abridgments, translations and paraphrases can still overlap substantially. Use the existing RB06/RB07 overlap evidence and underlying-work identities, not just original SHA equality.
5. **Implementation:** the current importer recognizes parent `evidenceOnly` flags but does not implement every contributor/quotation/component scope. Integrate those requirements before full-text teaching admission. This manifest marks every row `canImportWithoutFurtherReview: false`; that is a reconciliation decision, not a claim the current importer enforces this new field.
