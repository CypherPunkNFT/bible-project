# Cloud sessions

Run `git pull` first. When the work is done, commit and push straight to `main`, never to a side branch: the
owner checks the work on their PC from `main` (the desktop buttons in CLOUD_STARTER run `Start site.cmd` and
`Update site.cmd`). Pushing does not deploy the live site; releasing to bibleguide.io stays a separate, approved step.

The project rules are in [AGENTS.md](AGENTS.md).
