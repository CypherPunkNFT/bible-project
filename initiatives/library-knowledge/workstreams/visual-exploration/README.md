[Initiative](../../README.md) · [Task LK-407](../../TODO.md)

Help readers investigate evidence through clear tables and purposeful visualizations. Follow the existing graph plan's tables-first direction.

| Reader question | View | Required underlying evidence |
| --- | --- | --- |
| Who explains this passage? | Filterable passage explorer | Located treatments and relation class |
| Where do authors differ? | Comparison matrix | Reviewed attributed claims and qualifications |
| When does this formulation appear? | Timeline | Work/edition dates, uncertainty and source statements |
| What supports this argument? | Claim/evidence/objection diagram | Reviewed argument roles and locators |
| Which subjects connect? | Bounded topic map | Explained relations with examples |
| What belongs to this place and period? | Atlas layers | Place identities, dating and evidence types |
| What should I read next? | Learning pathway | Curated sequence, audience and prerequisites |

Inputs come from W1/W2/W3/W5. Deliver accessible table-first views with optional visual projections, filters, clear legends, source access and empty/uncertain states.

Execution checklist: identify the reader task; prototype one bounded dataset; verify filters and selection; provide keyboard/table access; test phone and desktop in both themes; measure whether the visual helps answer the question.

Acceptance: every connection can be explained and inspected. Avoid giant unlabeled network diagrams, precision unsupported by source dates, and graphs that imply consensus from frequency.

Boundary: preserve existing page hierarchy and routes; new navigation follows the Study plan rather than being invented within this workstream.
