## Upgrade priorities

1. Stable section identities, boundaries and literal-span/reader alignment.
2. Language-scoped concept senses and question retrieval using existing vectors alongside lexical/reference evidence.
3. Section-level co-citation, semantic neighbors and located textual-parallel evidence.
4. Attributed claims, quoted opponents, premises, replies and retained qualifications.
5. Historical/date-role and multilingual/translation relationships through existing research identities.
6. A reproducible evidence compiler that feeds several useful products from the same records.

The [design](DESIGN.md) turns these into proposed Python programs and contracts. It does not implement them. The next result should be a working section-to-evidence system followed by a supported-population run, with fresh evaluations showing useful questions answered. More inventories, interface proposals or successful hash checks alone do not meet that goal.
