# Visual audit: Bible Jeopardy (/games/jeopardy)

Audited 10 November 2026 on the local preview. I played the game through from a fresh start at desktop size (1440 wide) and again at phone size (390 wide): setup with three teams, a board built with the four choices on and a 20-second timer, a wrong answer and a steal, a tile shown without marking, the Daily Double with an all-in bet, the timer running out, the score adjuster, the game menu, a reload mid-game, ending the game early, the Final question with bets marked for every team, a tie for first place, the tie-breaker, the results, Play again, and a second desktop game with the choices and timer off, played by the keyboard. No code was changed. The screenshots are in [jeopardy/](jeopardy/). Names starting `desktop-` or `phone-` give the screen size, and the number gives the stage.

My step's own brief said only "audit Bible Jeopardy", so there was nothing to reconcile with the shared brief. I followed the shared brief as written. One thing I could not test: the game asks the browser to go full screen when you press Start game, and the audit browser refuses that, so every stage screenshot still shows the site's header and a one-line note offering the F11 key. On a real projector that note should not appear.

## What it looks and feels like now

This game is already more of a game than most on the site, because the board itself is the game. Setup is a long form ([desktop-02](jeopardy/desktop-02-setup-fullpage.png), [phone-02](jeopardy/phone-02-setup-fullpage.png)): Teams, with a counter, a name box per team and a dice button that gives a random friendly name; Board, with radio pills for columns, difficulty and testament and tick boxes for children's questions, the four choices and catechism; Rules, with turns or buzzing, penalties, Daily Double, Final question and timer. Then a blue Build board button. Choosing categories opens a long box of grouped tick boxes with question counts ([desktop-02b](jeopardy/desktop-02b-setup-choose-categories.png)). How to play is a plain modal with six bullets and a key table ([desktop-01](jeopardy/desktop-01-how-to-play.png)).

The preview, "Your board", shows the five columns as title, one-line description and five blue value slabs, with Swap, a Choose… drop-down and New questions under each, and a Final question line ([desktop-03b](jeopardy/desktop-03b-preview-top.png)). It is an admin page, and that is fine for the host.

Then the stage, and here it looks right ([desktop-04](jeopardy/desktop-04-board.png)). Five serif category titles over a five-by-five grid of deep blue tiles with big white values, a scoreboard strip along the bottom with numbered team dots in orange, teal and blue, a "TO CHOOSE" tag and an outlined box on the team whose turn it is, and a menu button. The light stage is a cream card with the same blue tiles ([desktop-10](jeopardy/desktop-10-board-light-stage.png)). It reads as Jeopardy from across a room.

Opening a tile swaps the board for the clue: category and value in the corners, a thin blue timer bar, the clue in large serif centred on the screen, the four choices as bordered boxes in two columns, and along the bottom each team's name with Right and Wrong pill buttons and a blue Show answer ([desktop-05](jeopardy/desktop-05-clue-choices-timer.png)). With the choices off it is just the big clue on black, which is the best-looking screen in the game ([desktop-05b](jeopardy/desktop-05b-clue-plain.png)). The swap has a quarter-second scale-in; that is the only motion between board and clue.

Marking a team wrong turns its buttons into a red "✗ Wrong" and the scoreboard shows "−100" with a small red delta beside it ([desktop-06](jeopardy/desktop-06-clue-wrong-mark.png)). Marking a team right jumps straight to the answer: the answer in huge serif, the right choice outlined teal, the verse in italic with a reference link, "Team 2 +100" in bold, and Back to board ([desktop-07](jeopardy/desktop-07-answer-right.png)). Back on the board the played tile is a dark grey empty slab ([desktop-08](jeopardy/desktop-08-board-one-played.png)).

The Daily Double is a form: "Daily Double" in serif, the team and its score, "Bet from 0 to 500", a number box, Half, All and 500 buttons, Back to board and Show clue ([desktop-11](jeopardy/desktop-11-daily-double-bet.png)). The clue then shows "Daily Double · 500" in the corner ([desktop-12](jeopardy/desktop-12-daily-double-clue.png)). When the timer runs out the bar vanishes and a small bold "Time" sits where it was ([desktop-15](jeopardy/desktop-15-clue-time-up.png)).

The Final question opens on a good title card: "Final question", the category in big serif, its one-line description, the instruction to write bets on paper, and Show the clue ([desktop-22](jeopardy/desktop-22-final-category.png)). The clue has a 30-second bar with a pause button ([desktop-23](jeopardy/desktop-23-final-clue.png)). The answer screen lists the teams lowest score first, each a bordered row with a bet box and Right and Wrong ([desktop-24](jeopardy/desktop-24-final-answer-marking.png)).

Results is a serif heading and a list: gold "1st", "2nd", "3rd", the team names, the scores, then Tie-breaker when first place is shared, Play again and New game ([desktop-26](jeopardy/desktop-26-results-tied.png), [desktop-29](jeopardy/desktop-29-results-after-tie-breaker.png)). The rows rise in over half a second. The tie-breaker is a clue screen headed "Tie-breaker" with only the tied teams' buttons ([desktop-27](jeopardy/desktop-27-tie-breaker-clue.png), [desktop-28](jeopardy/desktop-28-tie-breaker-answer.png)).

Underneath, the game is solid. Undo works, scores can be adjusted ([desktop-19](jeopardy/desktop-19-adjust-score.png)), a reload offers to carry on with the tile count and scores ([desktop-20](jeopardy/desktop-20-resume.png)), the keys do what the help says (arrows, Enter, Shift with a number for wrong, a number for right, Backspace for back), the board link copies, and the host sheet prints. No console errors in any run. The problem is that nothing is an event. A tile does not open, it is replaced. A right answer does not land, a score changes. The Daily Double does not happen, a form appears. The end is a list.

## Where it reads as a form or quiz instead of a game

- **The clue arrives like a page load.** Click a tile and the whole board is swapped for the clue with a faint fade. Nothing connects the tile you chose to the clue you see. The played tile afterwards is a grey slab, as if a button had been disabled.
- **Right and wrong are the same screen with a different word.** Wrong: the team's buttons become red text. Right: you are on the answer page. There is no flash, shake, sound or movement on the team's score, just a number that is now different, with a small "+100" or "−100" beside it that then stays there until the next change, even on the Final question screen ([desktop-22](jeopardy/desktop-22-final-category.png) still shows "+500" from the Daily Double).
- **The Daily Double is a bet form.** On television this is the loudest moment of the round. Here the tile quietly becomes a page with a number box and three small pills ([desktop-11](jeopardy/desktop-11-daily-double-bet.png), [phone-09](jeopardy/phone-09-daily-double-bet.png)).
- **The timer is a hairline.** A thin bar under the category, no colour change as it runs down, no numbers, and "Time" in ordinary bold when it ends ([desktop-14](jeopardy/desktop-14-clue-timer-running.png), [desktop-15](jeopardy/desktop-15-clue-time-up.png)). From the back of a hall it is invisible.
- **The choices look like a quiz.** Four bordered boxes with grey letters, the same component as a multiple-choice test. On the answer the right one gets a teal outline and nothing else ([desktop-07](jeopardy/desktop-07-answer-right.png)).
- **The Final question marks teams with a spreadsheet row.** Name, score, number box, two buttons, and "Wrong, −0" for a team that bet nothing ([desktop-25](jeopardy/desktop-25-final-bet-error-at-zero.png)). The reveal of each team's bet, which is the drama of Final Jeopardy, is a form field the host fills in.
- **The results are a table with ordinals.** "Results" is the heading whether the game was close or a rout. There is no winner's name in lights, no podium shape, no count-up, no confetti, and the scoreboard strip is still sitting underneath repeating the same numbers ([desktop-29](jeopardy/desktop-29-results-after-tie-breaker.png), [phone-19](jeopardy/phone-19-results.png)).
- **Setup is three forms stacked.** Twelve settings before a board appears. The dice button for team names is the one playful touch.

## How the best-known games of this kind do it

- **Jeopardy! on television.** The board is revealed category by category with a sound for each. A chosen tile flies out to fill the screen as the clue. The Daily Double is a full-screen animated card with its own fanfare before anyone bets. Scores sit on lit podiums in front of each player and visibly change. Final Jeopardy has the "think music", then each player's answer and bet are revealed one at a time, lowest score first, with the running score shown after each.
- **JeopardyLabs**, the free board most youth leaders already use: the tile flips over to show the clue, the clue flips again to show the answer, and the played tile fades out. Scores are big plus and minus buttons under the board. Simple, but the flip is what makes it feel like the show.
- **Factile**, the paid classroom version: tiles pop open with a sound, the board shows an animated Daily Double badge, a big circular timer counts down in colour, and the end screen names the winning team with a trophy.
- **Jeopardy! for the Nintendo Switch and PlayShow:** category reveal, buzzer sounds, a wrong answer buzzes and the podium flashes red, a right answer chimes and the podium flashes green, and the score counts up rather than jumping.
- **Kahoot! and Blooket** for the end: a three-step podium in colour, the winner's name largest, scores counting up, music and confetti. The site's own live youth-group quiz was audited earlier in this sequence with the same comparison, so the end screen can share one design.

## Improvements, ranked by impact for the effort

1. **Make the tile become the clue.** When a tile is clicked, it grows from its place on the board to fill the stage, and the clue appears on it, about a third of a second. On the way back the clue shrinks to the tile's place and the tile's value fades out, leaving the gap. One shared transform animation covers the Board, clue and answer screens; the clue's content does not change.
2. **Make a mark land.** Right: the team's pill flashes green, a short chime plays, and the score in the strip counts up to the new number over half a second while "+300" floats up and fades. Wrong: the team's pill shakes and flashes red, a low buzz plays, and the score counts down. Add "Sounds: on/off" to the game menu, remembered with the settings. The stale "+500" delta goes away because the float replaces it.
3. **Give the Daily Double its moment.** Before the bet form, the stage fills with the team's colour and the words "Daily Double!" zoom in from small to large with a sting, held for a second or until the host presses a key. The bet form then slides up underneath. The board tile that held it could flip to show a gold "DD" badge once played.
4. **Make the timer visible from the back of the room.** A bar three or four times thicker, blue for the first half, amber for the next, red and pulsing for the last five seconds, with the seconds as a number at its right end. When it ends, "Time!" stamps over the clue in large red serif with a buzz, and the mark buttons stay usable.
5. **Turn the results into a podium.** "Team 2 wins!" as the heading in the winner's colour, three columns of different heights in the team colours with the scores counting up, a confetti burst for the winner, and a drum before the tie-breaker when first is shared. Hide the scoreboard strip on this screen. The same podium can serve the live youth-group quiz.
6. **Reveal the Final question bets one at a time.** Keep the host's number box, but when Right or Wrong is pressed the row flips to show the result large and the team's score counts to its new value before the next row appears, lowest score first as now. "Wrong, −0" becomes "Bet nothing".
7. **Deal the board at the start.** When Start game is pressed, the category titles drop in one by one and the tiles fill column by column, about two seconds in all, with the "To choose" box sliding to the starting team. It is a small thing but it is the first impression on the projector.

## Phone problems

- **The board is unreadable at 390 wide** ([phone-04](jeopardy/phone-04-board-broken.png)). Five columns are forced into the width, the category titles break mid-word ("Davi d", "Creat ion and the fall") and the tile values overflow their tiles so each row reads as "1010101010 0". The tiles are still tappable, but nobody can tell which is which. On a phone the board needs to show one category at a time with the others as swipeable tabs, or stack the columns, or at the least shrink the value text to fit. The game says "Best on a laptop or TV" at the top, which is honest, but a host casting from a phone to a TV, or a leader checking the board before the night, gets this.
- **After Build board the page lands at the bottom.** On both sizes the preview opens scrolled to the Final question line and the site footer, so the board itself is above and out of view ([desktop-03](jeopardy/desktop-03-preview-as-landed.png), [phone-03](jeopardy/phone-03-preview-as-landed.png)). Scrolling to the top on that change would fix it.
- **The preview is a very long page on a phone.** Five columns stacked, each with five slabs and three controls ([phone-03c](jeopardy/phone-03c-preview-fullpage.png)). A compact list of category names with Swap beside each would do on a small screen.
- **The clue with the four choices needs scrolling to mark.** The choices are four tall boxes and the team buttons and Show answer are below them, off the first screen ([phone-05](jeopardy/phone-05-clue-fullpage.png)). The stage does not fill the phone's height, so the site footer shows under the game.
- **The scoreboard wraps to three lines** and the menu opens over the board ([phone-13](jeopardy/phone-13-menu.png)); the score adjuster is a cramped row of five controls ([phone-12](jeopardy/phone-12-adjust-score.png)).

## Accessibility

- **Good:** the board is a real grid for screen readers with one tile in the tab order at a time and clear labels ("Samuel, 300, open" or "played"); every score change is announced in a polite live region; the keys cover the whole game and are listed in the help; the bet boxes have hidden labels; errors use alerts; the game menu, confirmations and the other-tab notice have roles.
- **The timer is colour only.** Sighted players get a thin bar; nobody gets a number. A visible count would help everyone, not only screen-reader users, who do get a label.
- **The right choice is shown by colour alone** (a teal outline) on the answer screen. The answer is also printed in large text above, so the information is there, but a tick in the box would make it plain.
- **Small text on the stage:** "TO CHOOSE" and the delta numbers are tiny for a projected screen; the F11 notice is small grey text.
- **I could not see the keyboard focus ring** in the screenshot after pressing the arrow keys ([desktop-04b](jeopardy/desktop-04b-board-after-arrow-keys.png)). That may be the audit browser, which never had window focus, so it needs a check by hand: press the arrows on a real keyboard and confirm a gold ring moves between tiles.
- **Reduced motion is respected** for the few animations that exist.

## Anything broken

- **The phone board,** as above. This is the one real defect.
- **"Board link copied." lingers.** After Copy board link, then a full game, then Play again, the new preview still says "Board link copied." ([desktop-30](jeopardy/desktop-30-play-again-preview-stale-status.png)). The status should clear when a new board is dealt.
- **The score delta lingers** beside a team's score until its next change, across screens.
- **"Wrong, −0"** and "A bet is a whole number from 0 to 0." for a team at zero in the Final ([desktop-25](jeopardy/desktop-25-final-bet-error-at-zero.png)). Harmless, but it reads like an error.
- **The stage theme menu item does nothing on first press** on the dark site: the menu offers "Stage: dark" when the stage already is dark, and only after that "Stage: light". Offering light first when the site is dark would match what the host sees.
- **Replay a tile gives no visual cue** of which tiles can be chosen ([desktop-08b](jeopardy/desktop-08b-board-replay-mode.png)); the played slabs look as they always do. A highlight on the played tiles during replay mode would help.
