# Bible Firsts: the owner's additions (2026-11-12, binding)

The owner approved these 36 questions for Bible Firsts on top of the 25 already in
`src/data/what-came-first/firsts.source.json`, taking the category to about 61. Add each one to the source file in its normal
shape (question, answer, **the wrong answers given in the table** (replace one only if its verse check shows it could be defended as right, and say so in data-report.md), `never` names
where needed, refs, why, tier), check every verse's Berean wording as for the others, and show them on the review sheet.
**Drop a question only if its verse does not say what is claimed here; list any drop and why in data-report.md.**

The owner's clarifications, the same day:
- **Creation was ruled out as a category to play, not as a theme.** Questions that touch Genesis 1–3 are welcome (#1 and
  #12–14 below). The days-of-Creation category stays out.
- **No "first of the Ten Commandments" question** (the traditions number them differently). The owner prefers "the first and
  greatest commandment", which is already in the file (`first-greatest-commandment`).
- **Stephen's question says "the first Christian martyr"** (BRIEF.md §4a). Reword `first-killed-acts` to match.

Already in the file and so not repeated: Isaac's firstborn (Esau), David's firstborn (Amnon).
