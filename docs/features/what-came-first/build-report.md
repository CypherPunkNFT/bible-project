## 1. What was built

**The game moved and was renamed.** Who's older? is now **What came first?** at `/games/what-came-first`, in [src/pages/games/what-came-first/](Jarvis/Projects/BibleProject/Website/src/pages/games/what-came-first/). Its screens were moved from the old folder (git keeps them as renames where the file stayed close) and generalised. The approved Who's older? look and the games kit are kept: the same cards, hourglass, scoreboard, feedback band and result card, with the class names unchanged.

- **Start screen:** nine pills, all visible at once (People, Events, Rulers, Buildings, Journeys, Deaths, Books, Bible firsts, Mixed), no dropdown. **A new player opens on Mixed.** The address `?c=<kind>` chooses a pill; choosing one updates the address in place and is remembered. Under the pills: the chosen kind's question, a sample (two real cards with the hourglass, or a Bible Firsts question with its answers), Continue when a run is saved, Streak and Relaxed with that pill's bests, the difficulty chips, and the fold "How we decide what came first" with one sentence for the chosen kind.
- **Rounds:** the heading is the category's question ("Who ruled first?"). Journeys says "Where did Paul go first?" with the journey's name under it. In Mixed a small chip in the kind's colour names each round's kind, and the heading changes with it. The seven pair kinds show two tall cards with the hourglass (medallion: an initial for people, rulers and deaths; a scroll, a building or a map pin for events, buildings and stops; the book's code for books). Bible Firsts shows the question as the heading and three or four answer cards, two by two on a phone, one row on a desktop. Keys: 1/← and 2/→, and 1–4 for Bible Firsts.
- **Reveal:** right or wrong, what came first, the streak or hearts, and Next in the band's first row. Then the year strip (people, events, rulers, buildings, deaths), one reason sentence written whole for each kind, and the verse that settles it, quoted in the reader's own Bible through [Verse.tsx](Jarvis/Projects/BibleProject/Website/src/components/Verse.tsx) (fact pairs, journey stops, Bible Firsts). Books show "Ezra is book 15 of 66; 1 Peter is book 60." with links to open each book.
- **Dealing:** Who's older?'s rules in every pair kind: Streak and Relaxed, the difficulty ramp, no pair twice, one card stays, nobody three rounds running, the left card right about half the time. The general giveaway rule: an item that is first or last in every one of its pairs never stays (Genesis, Revelation, Adam). Journeys only pair two stops of one journey. Bible Firsts asks each of its 61 questions once, and a run that asks them all ends complete. Mixed draws each round's kind from the run's seed: never one kind three rounds running, Bible Firsts never twice running, and no card stays.
- **Best scores and saved runs:** kept per pill and mode under the browser key `bp-what-came-first`. **Who's older? players keep theirs:** the first time the page opens, the old `bp-whos-older` bests become Who lived first's, its saved run is copied into a Who lived first run (and resumes on the same pair, because Who lived first reads the unchanged Who's older? data), and they open on Who lived first (the People button). The old key is never changed or deleted, and the carry-over runs only once. A saved run resumes only if every kind it dealt from still has the same data stamp and every round is still askable; otherwise it is dropped and the bests stay.
- **The old address forwards:** `/games/whos-older` goes to `/games/what-came-first?c=lived`, which opens the game on Who lived first, the category whose button is labelled People (one route in [App.tsx](Jarvis/Projects/BibleProject/Website/src/App.tsx), because the games hub sends unknown game addresses to the hub).
- **Hub and app tile:** the registry entry (same place on the family shelf) has the new address, title and description ("Two people, events, kings, places or books: tap the one that came first. Eight kinds of round, or all mixed."). The hub picture is unchanged; its description now ends "which came first?". The phone app's tile was regenerated from the committed site, its two captured drawings re-captured under the new name with the new description, and its picture map updated.
- **Translation:** the on-screen words of the six generated data files are registered in [extract.py](Jarvis/Projects/BibleProject/Website/content/translation/extract.py); `what-came-first/` is added to the language packer's list; the hand-kept source files, the book list and the unused journey "origin" field are recorded as reviewed in [unregistered-reviewed.json](Jarvis/Projects/BibleProject/Website/content/translation/unregistered-reviewed.json). Every word on the page passes the English build check.

Where this departs from the design, and why, is written in the design's new "Implementation notes" section in [design.md](Jarvis/Projects/BibleProject/Website/docs/features/what-came-first/design.md). The main ones: every kind's data loads when the page opens (Mixed is the default and needs all of it); a saved Bible Firsts answer is stored as its place in the answer list, not its place on screen; the planned per-category adapter files became two small functions.

Before any code was written, a separate review agent checked the plan from three angles (correctness and security, how it fails, edge cases). It found nothing critical and four major problems, all fixed in the plan first: storage is never touched before the data has loaded; Bible Firsts falls back to harder as well as easier questions, so Relaxed on Easy or Hard still reaches every question; the carry-over keeps the old bests even when the old saved run is broken, and does nothing with corrupt data; and the app's typecheck and games-hub test were run as well as `check:site`.

## 5. Left undone, and why

- **Two owner points from the design stay open, as the brief left them:** whether the book cards should show their section of the Bible (they do, as the design review recommended), and whether the hub picture should be redrawn for the new game (it is still the two portraits and the hourglass; only its description changed).
- **Book names stay in English** in other languages: the book list is not sent for translation, like the other games' book lists. Every other word of the game's data is registered and will be translated by the next translation run; until then other languages show the English, as with any new text.
- **The Events data file is 502,579 bytes**, just over half a megabyte. It downloads on its own, only on this page, and the build gave no warning, so it was left as it is rather than trimming its facts.
- **The forward is tested** by checking the route in App.tsx and by playing that same route through the games hub in a test router, not by rendering the whole site in a test, which would need every provider the site has. The preview run shows the real site forwarding.
- **Not deployed**, as the brief says.
